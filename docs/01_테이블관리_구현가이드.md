# 엑셀 업로드 → DB 테이블 관리 구현 가이드 (범용)

> 목적: 엑셀 파일을 읽어 화면에 보여주는 Python/Streamlit 앱을,
> **"엑셀 업로드 → DB 테이블 자동 구축 → 조회·편집 관리"** 구조로 전환하는 **재사용 가능한 구현 패턴**.
> 신규 솔루션 구상 시 그대로 가져다 쓰기 위한 참고용 문서. 예시 프레임워크는 Streamlit, 예시 테이블명은 `my_table`.

---

## 0. 두 가지 접근 — "파일 저장" vs "테이블 관리"

엑셀을 다루는 앱은 보통 아래 (A) 상태에서 시작한다. 목표는 (B)다.

| 구분 | (A) 파일 저장 방식 (Before) | (B) 테이블 관리 방식 (After) |
|------|------------------------------|-------------------------------|
| 저장 단위 | 엑셀 **파일 통째**(Storage/로컬) | **행(row) 단위**로 DB 테이블에 적재 |
| 조회 | 볼 때마다 pandas **재파싱** | DB에서 **SELECT** |
| 편집 | 불가(엑셀이 유일 원천) | 앱에서 **셀 편집 → DB 반영(CRUD)** |
| 집계/필터 | 전부 인메모리 pandas | **DB 쿼리**로 위임 가능 |

> (A)의 전형적 냄새: "업로드한 파일을 세션/버킷에 넣고, 화면에서 매번 `pd.read_excel`로 다시 읽는다." → 개별 행 조회·수정·SQL 집계가 안 된다.

---

## 1. 목표 구조 (After)

```
┌────────────┐   업로드   ┌──────────────────┐   to_sql   ┌──────────────────┐
│  사용자     │ ───────▶ │ 앱 (Streamlit 등)  │ ────────▶ │ Postgres 테이블   │
│ (xlsx)     │          │  pandas 파싱       │  자동 DDL  │ my_table / ...    │
└────────────┘          └──────────────────┘            └──────────────────┘
                               ▲   조회(read_sql)               │
                               └────────────────────────────────┘
                               편집: st.data_editor → to_sql(write-back)
```

**핵심 아이디어:** pandas `df.to_sql(name, engine, if_exists="replace")` 한 줄이면
**엑셀 컬럼 구조 그대로 테이블을 자동 생성/재구축**한다. 수동 `CREATE TABLE` DDL이 필요 없다.
이것이 "엑셀 업로드로 테이블이 구축된다"의 코드 구현이다.

> ⚠️ **왜 Supabase 파이썬 클라이언트(`supabase-py`)가 아니라 직접 Postgres 연결인가?**
> `supabase-py`는 PostgREST(REST) 기반이라 **코드에서 테이블을 만들 수 없다**(사전에 스키마가 있어야 함).
> 반면 **직접 Postgres 연결(SQLAlchemy) + `to_sql`** 은 테이블 자동 생성이 되므로 "엑셀→테이블 구축" 요구에 정확히 맞는다.
> Supabase·Neon 등 대부분의 무료 Postgres가 연결 문자열을 제공하므로 그대로 쓸 수 있다. (DB 선택은 → `02_무료DB_비교...md`)

## 2. 사전 준비

### 2-1. 의존성

```txt
streamlit>=1.35.0        # UI (다른 프레임워크면 생략)

psycopg2-binary>=2.9.0   # ← Postgres 드라이버
```

### 2-2. 연결 문자열 확보

- **Supabase:** 대시보드 → **Project Settings → Database → Connection string → "URI"**. 외부 앱(클라우드 배포 등)에서는 반드시 **Connection Pooling의 "Session mode"**(IPv4 지원):
  ```
  postgresql://postgres.xxxx:[DB비밀번호]@aws-0-<region>.pooler.supabase.com:5432/postgres
  ```
  `[DB비밀번호]`는 **DB 비밀번호**(anon key와 다름).
- **Neon:** 대시보드 → **Connection Details → Connection string** (`?sslmode=require` 포함).

> 연결 문자열만 바꾸면 아래 코드는 어떤 Postgres에서도 동일하게 동작한다.

### 2-3. 시크릿 등록 — `.streamlit/secrets.toml` (또는 `.env`)

```toml
DATABASE_URL = "postgresql://<user>:<password>@<host>:5432/<database>"
```

> 시크릿 파일은 반드시 `.gitignore`에 넣어 커밋 제외.

## 3. DB 접근 모듈 — `db.py`

앱 로직과 DB 접근을 분리한다. 신규 파일 하나. **이 모듈은 도메인 무관하게 그대로 재사용**된다.

```python
# db.py
import os
import pandas as pd
import streamlit as st
from sqlalchemy import create_engine, text
from sqlalchemy.engine import Engine


@st.cache_resource(show_spinner=False)
def get_engine() -> Engine | None:
    """SQLAlchemy 엔진 (커넥션 풀). 캐시되어 재사용된다."""
    url = st.secrets.get("DATABASE_URL", os.getenv("DATABASE_URL", ""))
    if not url:
        return None
    # pool_pre_ping: 유휴 커넥션 끊김(무료 티어 pause 등) 자동 복구
    return create_engine(url, pool_pre_ping=True, pool_recycle=280)


def db_ready() -> bool:
    return get_engine() is not None


def save_df(table: str, df: pd.DataFrame, mode: str = "replace") -> int:
    """DataFrame을 테이블로 저장. mode='replace'면 테이블을 자동 생성/재구축한다.

    반환: 저장된 행 수. DB 미설정/빈 df면 -1.
    """
    eng = get_engine()
    if eng is None or df is None or df.empty:
        return -1
    df = df.copy()
    df.columns = [str(c).strip() for c in df.columns]   # 컬럼명 공백 정리
    df.to_sql(
        table, eng,
        if_exists=mode,     # 'replace' = DROP+CREATE (엑셀 스키마로 자동 구축)
        index=False,
        chunksize=1000,
        method="multi",     # 다중 행 INSERT (속도)
    )
    return len(df)


def load_df(table: str) -> pd.DataFrame | None:
    """테이블 전체를 DataFrame으로 로드. 테이블 없거나 DB 미설정 시 None."""
    eng = get_engine()
    if eng is None:
        return None
    try:
        return pd.read_sql(text(f'SELECT * FROM "{table}"'), eng)
    except Exception:
        return None


def table_exists(table: str) -> bool:
    eng = get_engine()
    if eng is None:
        return False
    with eng.connect() as c:
        return bool(c.execute(text("SELECT to_regclass(:t) IS NOT NULL"),
                              {"t": table}).scalar())
```

**설계 포인트**
- `@st.cache_resource` — 엔진(커넥션 풀)은 세션·재실행 간 재사용. 매번 새로 만들지 않는다.
- `pool_pre_ping=True` — 무료 티어가 유휴로 pause됐다 깨어날 때 끊긴 커넥션을 자동 복구.
- `if_exists="replace"` — **엑셀을 새로 올리면 테이블을 통째로 다시 만든다**(스냅샷 모델). 편집 후 write-back에도 안전.
- 한글·`할인율(%)` 같은 특수문자 컬럼명도 `SELECT *`로 왕복하면 그대로 보존된다. 화면 코드가 `df["할인율(%)"]`처럼 원본 컬럼명을 그대로 써도 동작한다.

> **Streamlit이 아닌 경우(FastAPI 등):** `@st.cache_resource`/`st.secrets`만 걷어내고 `create_engine(os.environ["DATABASE_URL"], pool_pre_ping=True)`로 바꾸면 그대로 쓸 수 있다.

## 4. 업로드 핸들러 — 파싱 결과를 DB에 적재

파일 업로더에서 엑셀을 파싱한 직후 `save_df`를 호출한다. **여러 데이터셋을 다루면 (표시명 → 테이블명) 딕셔너리로 일반화**한다.

```python
import db
import pandas as pd
import streamlit as st

# 업로드 대상 정의: 표시명 → (테이블명, 시트명 or None)
DATASETS = {
    "매출 원본":  ("my_table",     "Sheet1"),
    "월별 집계":  ("monthly",      "Summary"),
}

for label, (table, sheet) in DATASETS.items():
    up = st.file_uploader(label, type=["xlsx"], key=f"up_{table}")
    if up:
        df = pd.read_excel(up, sheet_name=sheet) if sheet else pd.read_excel(up)
        # (필요하면 여기서 정제: 컬럼 strip, 타입 변환, dropna 등)
        n = db.save_df(table, df)                     # ← 테이블 자동 구축/적재
        if n >= 0:
            st.success(f"'{table}' 테이블에 {n:,}행 저장 완료")
        else:
            st.warning("DB 미연결 — 세션에만 보관")
        st.dataframe(df.head(), use_container_width=True)
```

> **엑셀 1개에 시트가 여러 개**면 시트마다 테이블을 만든다:
> ```python
> for sheet, sdf in pd.read_excel(up, sheet_name=None).items():   # None → 전체 시트 dict
>     db.save_df(sheet.lower().replace(" ", "_"), sdf)
> ```

## 5. 조회 경로 — 파일 재파싱 대신 테이블 읽기

DB 우선, 없으면 기존 파일 방식으로 폴백(하위호환).

```python
@st.cache_data(ttl=600, show_spinner=False)   # 10분 캐시
def load_table(table: str):
    return db.load_df(table)

def get_data(table: str, fallback_path: str | None = None):
    df = load_table(table)                     # 1순위: DB
    if df is None and fallback_path:           # 2순위: 로컬 파일 폴백
        import os
        if os.path.exists(fallback_path):
            df = pd.read_excel(fallback_path)
    return df
```

- **DB가 진실원천**이 되고, 아직 아무것도 안 올렸으면 샘플 파일로 폴백하므로 화면이 깨지지 않는다.
- 업로드 직후에는 캐시를 무효화한다: 4번 핸들러 끝에 `load_table.clear()` 추가.

## 6. 편집 기능 — "데이터 관리" 화면 (핵심)

"테이블 **관리**"의 실체. `st.data_editor`로 스프레드시트처럼 편집 → DB에 write-back.

```python
import db, streamlit as st
from io import BytesIO

if not db.db_ready():
    st.error("DATABASE_URL 미설정. secrets.toml 확인."); st.stop()

TABLES = {"매출 원본": "my_table", "월별 집계": "monthly"}
label = st.selectbox("편집할 테이블", list(TABLES))
table = TABLES[label]

df = db.load_df(table)
if df is None or df.empty:
    st.info("데이터 없음. 먼저 업로드하세요."); st.stop()

st.caption(f"{len(df):,}행 · {len(df.columns)}열 — 셀 더블클릭 편집, 행 추가/삭제 가능")
edited = st.data_editor(df, use_container_width=True,
                        num_rows="dynamic", key=f"edit_{table}", height=520)

c1, c2 = st.columns([1, 5])
with c1:
    if st.button("변경사항 저장", type="primary"):
        n = db.save_df(table, edited, mode="replace")   # 전체 스냅샷 교체
        load_table.clear()
        st.success(f"{n:,}행 저장 완료. 화면에 즉시 반영됩니다.")
with c2:
    buf = BytesIO(); edited.to_excel(buf, index=False)
    st.download_button("현재 상태 엑셀 다운로드", buf.getvalue(),
                       file_name=f"{table}.xlsx")
```

**동작:** 셀 편집 / 행 추가·삭제(`num_rows="dynamic"`) → 저장 → `to_sql(replace)`로 테이블 통째 갱신 → 화면 즉시 반영. 편집 결과를 엑셀로 재다운로드해 백업 가능(양방향).

## 7. 마이그레이션 순서 (안전 절차)

1. 의존성 추가(SQLAlchemy·psycopg2) → 설치.
2. `secrets.toml`에 `DATABASE_URL` 추가.
3. `db.py` 추가.
4. **읽기 경로부터** 폴백 포함으로 전환(5번) → DB가 비어도 기존 파일로 동작(무해).
5. 업로드 핸들러에 `save_df` 추가(4번) → 한 번 업로드해서 테이블 생성 확인.
6. "데이터 관리" 화면 추가(6번).
7. DB 대시보드의 **Table Editor**에서 테이블이 생겼는지 눈으로 확인.

**롤백:** `get_data()`의 DB 조회부만 주석 처리하면 즉시 기존 파일 방식으로 복귀. `db.py`·업로드 코드는 남겨도 무해(폴백이 받쳐줌).

## 8. 스냅샷 vs 이력(버전) 모델 — 트레이드오프

| 모델 | 방식 | 장점 | 단점 |
|------|------|------|------|
| **스냅샷(기본)** | `if_exists="replace"` | 단순·최신 1벌 유지 | 과거 업로드 이력 없음 |
| **이력(버전)** | `if_exists="append"` + `uploaded_at`/`source_month` 컬럼 | 월별 추이·감사 추적 | 조회 시 최신 스냅샷 필터 필요 |

이력이 필요하면 `save_df`에서 `df["uploaded_at"] = pd.Timestamp.utcnow()` 추가 후 `mode="append"`, 조회는 `WHERE uploaded_at = (SELECT max(...))`로 최신만. "최신 파일 1개"만 보는 화면이면 **스냅샷 모델로 시작** 권장.

## 부록 A. supabase-py 클라이언트(REST) 대안 (참고)

이미 있는 스키마에 REST로 쓰는 방식. **테이블 자동 생성은 안 되므로** 대시보드에서 미리 테이블을 만들어야 한다. `to_sql`보다 제약이 많아 **비권장**이지만, RLS/anon key만 쓰는 환경에서는 이 방법뿐이다.

```python
# 사전: DB에서 CREATE TABLE my_table (...) 수동 생성 필요
records = df.where(pd.notna(df), None).to_dict("records")
for i in range(0, len(records), 500):                    # 청크
    sb.table("my_table").upsert(records[i:i+500]).execute()
rows = sb.table("my_table").select("*").execute().data
df = pd.DataFrame(rows)
```

## 부록 B. 자주 나는 오류

| 증상 | 원인 / 해결 |
|------|-------------|
| `could not translate host name` / 연결 timeout | 직접(5432 direct) 대신 **Pooler(Session mode)** URI 사용. IPv4 문제 회피. |
| 업로드는 되는데 화면에 반영 안 됨 | 캐시 무효화(`load_table.clear()`) 누락. |
| `SSL connection has been closed unexpectedly` | 무료 티어 pause에서 깨어난 직후. `pool_pre_ping=True`(설정됨)면 다음 요청에서 자동 복구. |
| 한글/`(%)` 컬럼 쿼리 실패 | 식별자를 큰따옴표로 인용: `SELECT "할인율(%)" FROM my_table`. `SELECT *`는 문제없음. |
| 무료 티어 용량(예: Supabase 500MB) 초과 | DB가 read-only 전환. 오래된 스냅샷/이력 정리 또는 다른 DB(Neon 등)로 이전. |
